How we work together

Audit

A focused review of an existing Android or KMP codebase — architecture, public API surface, and the real risk in a multiplatform migration. Fixed fee, one to two weeks, ends with a written plan.

Fixed-scope build

A defined deliverable — a library, an SDK, a Compose Multiplatform migration — scoped, priced, and shipped against a clear definition of done.

Retained engineering

Senior KMP and Android capacity for a team that needs it, by the month. Reviews, architecture, and the hard parts of the shared module.

The kind of problem we solve

  • Take an Android-only library multiplatform without breaking it. DrawBox went from Android to Android, iOS, web, and desktop on one source set — and kept its public API. That is a migration, not a rewrite, and it is the one we do best.
  • Build tooling that works offline and keeps no secrets. Universal Context Pipeline is a local-first MCP server: no cloud, no telemetry, a single Rust binary. When the constraint is privacy, the architecture has to earn it.
  • Ship developer tooling that maintains itself. statsvg_rs renders and republishes its own stats every six hours with zero servers. Small, boring, and it never pages you.
